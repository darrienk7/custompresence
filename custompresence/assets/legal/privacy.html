Privacy Policy

Effective October 22, 2026

This policy describes the current desktop version of Custom Presence. There is no central presence-account, analytics, advertising, or permanent image-storage backend operated by the app. Configured builds may use an upload service that forwards selected files to ImgBB. External services process information under their own policies.

Information stored on your computer

The app saves your last successfully applied activity settings in its local application-data folder. This includes activity type and name, text, public image and button links, timestamps, party configuration, and display options. Join, spectate, and match tokens are held for the current session and sent to Discord when you apply them, but are excluded from saved settings. The app does not request Discord account tokens or passwords and does not save account credentials or upload keys in activity settings.

A separate local upload index remembers up to 100 recently used files by a SHA-256 fingerprint of their contents. It stores each fingerprint, the public image URL, any host removal link, image format and dimensions, and last-use time. This allows the same file to reuse its existing hosted copy after restarting the app. The index does not contain original file bytes, original filenames, or local file paths. Removal links can allow deletion, so treat this local index as private.

The desktop webview uses a private browser session so browser history and old form values are not intentionally retained between launches. Temporary browser files may exist while the app runs; older app versions may have left a persistent webview folder in local application data. Activity settings and upload history are kept separately as described above. Startup and shutdown logs are stored in the app’s local log folder for troubleshooting. The app does not intentionally log activity text, invite tokens, upload keys, or uploaded image links. Logs are not automatically transmitted to the maintainers. App owners may configure an ImgBB API key through an ignored local .env file or environment variable for testing; ordinary users are not asked to enter a key, and released builds do not bundle the account key.

Discord

When you apply an activity, the app sends the selected presence fields to your signed-in Discord desktop client through a local connection. Discord processes and displays that information according to your account settings and Discord’s Privacy Policy. Treat presence text, image links, party information, and configured buttons as information intended for others to see. Game-invite tokens may be shared through Discord’s game-integration features.

Images and the upload host

Selecting a file sends its bytes through the app’s local connection. If the same contents are remembered, the app checks the existing URL with ImgBB and reuses it unless the host reports that it is gone. Otherwise, in a configured released build, a project upload service receives that file and your connection information, forwards the file to ImgBB, and returns its public image URL and any removal link supplied by ImgBB. File fingerprints are used locally and are not sent to that service. The service handles files in memory rather than intentionally saving them to permanent storage. It uses source IP addresses for one-minute rate-limit windows; expired records are removed on the next upload request or process restart. Hosting providers can process connection information and operational logs under their own policies. No activity text, Discord account token, invite tokens, or saved settings are sent to this upload service.

On an owner’s computer configured with a local ImgBB key, files go directly from the local app to ImgBB without the shared upload service. ImgBB receives file bytes and embedded metadata, the uploading connection’s IP address, and the owner’s API credentials needed to perform the upload. The original filename is replaced with a generic filename. Browser cookies and browser login state are not used for API uploads.

Uploaded images and GIFs are public and may contain embedded metadata supplied in the original file; metadata removal is not guaranteed. The app does not intentionally store uploaded file bytes on disk. Returned public URLs can be saved as activity settings. Removal links are shown for you to retain and saved in the separate local upload index. Selecting the same file again can display its remembered removal link. Cancelling a request does not guarantee cancellation or deletion at the host once file transmission has begun.

ImgBB’s Privacy Policy and Terms of Service govern its processing, retention, moderation, and deletion of uploaded media. This project cannot guarantee the host’s detection or removal of inappropriate images, the duration of hosting, or the deletion of copies made by others.

Public links and preview requests

When an image link is entered or restored, the app’s preview requests the image from that host. Checking or applying a link also downloads its image into local memory to verify the format and size. Giphy, Tenor, and single-image Imgur page links are converted to direct image URLs. The host receives normal connection information, including your IP address. These link checks do not use the project upload service. Discord may also fetch the linked image for your presence. External buttons, text links, removal links, and policy links contact their destinations if opened. Clearing an activity or resetting local settings does not delete hosted files or remove copies held by external services.

Your choices

You can use public links instead of uploading, clear the activity, close the app to disconnect it, and use Advanced → Saved data → Reset saved settings to remove the settings file. Forget remembered uploads in that same screen removes the local upload index; it does not delete hosted files or remove image URLs already saved in activity settings. The least recently used index entries are also discarded when more than 100 files are remembered. Local logs and webview cache can be removed from the CustomPresence folders under your operating system’s application-data and log locations. Request deletion of hosted media through the image host, retaining removal links before clearing upload history. Do not upload confidential information or content that you do not intend to make publicly accessible.

Service eligibility, changes, and contact

You must meet the eligibility rules of Discord and any host you use. Changes to this policy will be published with a new effective date. For privacy questions or requests, contact the project maintainer at chasekw2007@gmail.com. If you email the maintainer, your email address and message are received by that mailbox provider and used to respond to your request. Do not send passwords, account tokens, or upload API keys. Requests to remove hosted images must also be directed to the relevant host.
